Aราคาตามช่วงเวลา + ส่วนลด

เข้าเมนู ทรัพยากร (Resources)

เปิด ใช้ราคาตามช่วงเวลา / ส่วนลดชั่วโมงต่อเนื่อง

เลือกบริการ แล้วกด ＋ เพิ่มช่วงราคาใส่เวลา จาก – ถึง และราคาต่อรอบ (00:00 = เที่ยงคืน) เลือกเฉพาะสนาม/สาขา/วันได้

ตั้ง ส่วนลดเมื่อจองรอบต่อเนื่อง เป็นบาทหรือ % แล้วกด บันทึกราคาลูกค้าเห็นราคาใหม่ภายใน 1 นาที

💡ส่วนลดต่อเนื่อง คิดเมื่อรอบแรกจบตรงกับรอบถัดไปเริ่ม — ร้านที่ตารางเวลาเป็นรายชั่วโมง ให้ตั้งระยะเวลาบริการ 60 นาที ที่เมนูบริการ

Bแพ็กเกจชั่วโมง

เข้าเมนู แพ็กเกจชั่วโมง กด เพิ่มแพ็กเกจตั้งจำนวนชั่วโมง ราคา อายุ (วัน) บริการ และช่วงเวลาที่ใช้ได้

ขายที่ร้าน: กด ขายแพ็กเกจที่ร้าน ใช้ได้ทันทีขายใน LINE: เปิด “ขายใน LINE” ลูกค้าสแกนพร้อมเพย์ + ส่งสลิป แล้วร้านกดอนุมัติ

ลูกค้าจองคิว เลือก ชำระด้วยแพ็กเกจ ระบบตัดชั่วโมงให้เองยกเลิกคิว = คืนชั่วโมง · ไม่มาตามนัด = ไม่คืน

Cปรับข้อความในหน้าจอง

ที่เมนู ทรัพยากร (Resources) เปิด/ปิดข้อความใต้ตารางเวลาได้ทีละบรรทัด: คำแนะนำเลือกหลายช่อง · ราคาต่อรอบ · ข้อความส่วนลด (ปิดแค่ซ่อนข้อความ ราคาคิดเหมือนเดิม)

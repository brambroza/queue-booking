เชื่อมต่อ LINE OA กับ QueueBooking

1

สร้าง LINE Official Account

LINE OA Manager
https://manager.line.biz/
  1. เข้าสู่ระบบด้วยบัญชี LINE
  2. กด “สร้างบัญชีทางการ” แล้วกรอกชื่อร้าน ประเภทธุรกิจ อีเมล และเบอร์โทร
  3. สร้างบัญชีให้เสร็จ
ได้อะไรกลับมาLINE OA ID เช่น @myshop
มี LINE OA อยู่แล้ว ข้ามขั้นนี้ได้เลย
2

เปิด Messaging API

LINE OA Manager
  1. เลือก OA ของร้าน แล้วไปที่ Settings → Messaging API
  2. กด “Enable Messaging API”
  3. ตั้งชื่อ Provider เป็นชื่อร้าน แล้วกดยืนยัน
ได้อะไรกลับมาChannel ID, Channel Secret และ Messaging API Channel ใหม่
3

คัดลอก Channel Secret และออก Channel Access Token

LINE Developers Console
https://developers.line.biz/console/
  1. เลือก Provider ของร้าน แล้วเลือก Messaging API Channel ที่สร้างไว้
  2. แท็บ Basic settings: คัดลอก Channel secret
  3. แท็บ Messaging API: เลื่อนลงที่ “Channel access token (long-lived)” กด Issue แล้วคัดลอก
นำไปใส่ใน Portalตั้งค่า LINE → Channel Access Token และ Channel Secret แล้วกดบันทึก
Token และ Secret คือรหัสผ่านของ OA ห้ามส่งต่อหรือโพสต์ในกลุ่ม
4

ตั้งค่า Webhook

Portal + LINE Developers
  1. ใน Portal เปิด ตั้งค่า LINE แล้วคัดลอก Webhook URL ของร้าน
  2. กลับไปที่ LINE Developers Console → Messaging API → Webhook settings
  3. วาง URL เปิด Use webhook เป็น ON แล้วกด Verify
https://queuebooking.com/api/line/webhook/{shopKey}
ผลที่ถูกต้องกด Verify แล้วขึ้น Success
5

ตั้งค่าการตอบกลับใน OA Manager

LINE OA Manager

ไปที่ Settings → Response settings แล้วตั้งค่าตามนี้ เพื่อให้ระบบเป็นตัวตอบแชทหลัก

หัวข้อตั้งเป็น

{shopKey} ของร้านดูได้ที่หน้า ตั้งค่า LINE ใน Portal Endpoint ต้องขึ้นต้นด้วย https เท่านั้น
7

สร้างและเผยแพร่ Rich Menu

Portal
  1. ใน Portal เปิดเมนู สร้าง Rich Menu
  2. เลือกประเภทธุรกิจและแบบเมนู ระบบจัดปุ่ม ไอคอน และข้อความภาษาไทยให้
  3. กด บันทึกรูปลงระบบ แล้วกด เผยแพร่ไป LINE
ผลที่ได้เมนูจองคิว เช็คคิวของฉัน ติดต่อร้าน ขึ้นที่ด้านล่างแชท LINE OA ของร้าน
ต้องใส่ LIFF ID ให้เรียบร้อยก่อน ระบบจึงจะเผยแพร่ได้ Rich Menu ที่เผยแพร่จากระบบจะไม่แสดงใน LINE OA Manager ให้จัดการจากหน้า Portal
8

ทดสอบจองคิวด้วยตัวเอง

LINE + Portal
  1. เพิ่ม LINE OA ของร้านเป็นเพื่อน แล้วกดเมนู “จองคิว”
  2. เลือกสาขา บริการ วันและเวลา แล้วยืนยันการจอง
  3. เปิดหน้า “การจอง” ใน Portal เพื่อดูคิวที่เข้ามา และลองกด “เรียกคิว”
เสร็จครบ 5 ขั้นตอนเมื่อมีคิวแรกเข้าระบบ ทีมงาน QueueBooking จะตรวจและเปิดระบบให้รับคิวจากลูกค้าจริง

ติดปัญหา? ลองตรวจตามนี้

Verify Webhook ไม่ผ่าน

  • URL ขึ้นต้นด้วย https
  • คัดลอก URL จาก Portal ครบทั้งบรรทัด
  • บันทึก Token และ Secret ใน Portal แล้ว

Bot ไม่ตอบแชท

  • Use webhook เป็น ON
  • Auto-reply messages เป็น OFF
  • Channel Access Token ถูกต้อง ไม่หมดอายุ

LIFF เปิดไม่ได้

  • Endpoint URL ตรงกับร้านและเป็น https
  • LIFF ID ที่ใส่ใน Portal ถูกตัว (จอง / สมาชิก)
  • เปิดผ่านแอป LINE ไม่ใช่เบราว์เซอร์

กดปุ่ม Rich Menu แล้วไม่เปิด

  • ใส่ LIFF ID แล้วและเผยแพร่ใหม่
  • ปิดแชทแล้วเปิดใหม่เพื่อโหลดเมนูล่าสุด

เช็กลิสต์ก่อนรับลูกค้าจริง

  • สร้าง LINE OA
  • ใส่ LIFF ID ทั้ง 2 ตัว
  • เปิด Messaging API
  • เผยแพร่ Rich Menu
  • ใส่ Channel Secret / Token
  • ทดสอบจองคิวผ่าน LINE
  • ตั้งค่า Webhook และ Verify ผ่าน
  • ทดสอบเรียกคิว และแจ้งเตือน LINE

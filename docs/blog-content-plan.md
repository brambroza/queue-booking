### ข้อควรระวังเรื่องคำค้น

คำในคอลัมน์ "คำที่คาดว่าคนค้น" เป็นสมมติฐานจากความสามารถของระบบและธุรกิจเป้าหมาย
ยังไม่ได้ตรวจปริมาณค้นจริง ก่อนล็อกลำดับให้ตรวจด้วย Google Search Console (คำที่เว็บติดอยู่แล้ว)
และ Google Keyword Planner (ปริมาณค้น) แล้วสลับลำดับตามผล

### ข้อควรระวังเรื่องเนื้อหา

- สัปดาห์ 3: การจ่ายผ่านแอป SCB Easy / K PLUS โดยตรงยังไม่ได้ทดสอบกับธนาคารจริง อย่าเขียนว่าใช้งานได้ ให้เล่าเฉพาะ PromptPay, แอปธนาคารผ่าน Omise และโอนแนบสลิป
- สัปดาห์ 4: ระบบอนุมัติสลิปอัตโนมัติเฉพาะเมื่อธนาคารยืนยันยอดได้ ซึ่งยังไม่ได้เชื่อมต่อ ตอนนี้ระบบตรวจได้ว่า QR บนสลิปถูกรูปแบบและไม่ซ้ำ แล้วส่งให้พนักงานอนุมัติ ให้เขียนตามนี้ ห้ามเขียนว่าระบบยืนยันยอดเงินอัตโนมัติ
- สัปดาห์ 7: ยังไม่มีหน้าธุรกิจฟิตเนสให้ลิงก์ไป ต้องสร้างหน้าก่อน หรือเลื่อนบทความนี้ไปท้ายแผน
- ตัวเลขผลลัพธ์ (เช่น ลดลูกค้าไม่มา กี่เปอร์เซ็นต์) ใช้ได้เฉพาะที่มีข้อมูลจากร้านจริงรองรับ

## 4. โครงบทความมาตรฐาน

1. ปัญหาของเจ้าของร้าน เล่าเป็นสถานการณ์จริงในร้าน
2. วิธีที่ร้านทำอยู่ตอนนี้ และสิ่งที่เสียไป (เวลา, ลูกค้า, เงิน)
3. วิธีทำในระบบ ทีละขั้น พร้อมภาพหน้าจอจริง
4. ตัวอย่างร้านหนึ่งประเภท
5. คำถามพบบ่อย 3–5 ข้อ
6. ชวนทดลองใช้ฟรี

- ความยาว 800–1,200 คำไทย
- ภาพหน้าจอจริง 3–5 ภาพ และภาพปก 1 ภาพ
- ภาพหน้าจอถ่ายด้วย `npm run screenshots` (ดู `scripts/screenshots/README.md`)
- ภาพจาก LINE และแอปธนาคารต้องถ่ายจากมือถือด้วยมือ และต้องปิดชื่อกับเบอร์โทรก่อนใช้

## 5. รายการปรับระบบ blog ที่เสนอ

ยังไม่ได้ทำ เรียงตามความสำคัญ

| ลำดับ | รายการ | ผลถ้าไม่ทำ |
|---|---|---|
| 1 | sitemap สร้างลิงก์หน้าอังกฤษจากรายการบทความไทย | 2 ลิงก์ใน sitemap เปิดแล้วไม่พบหน้า |
| 2 | เพิ่มภาพปกและภาพสำหรับแชร์ต่อบทความ | แชร์ลง LINE/Facebook แล้วทุกบทความขึ้นภาพเดียวกัน |
| 3 | ให้เนื้อหาใส่ลิงก์ รายการ และภาพแทรกได้ | บทความสอนทีละขั้นต้องเลื่อนไปดูภาพท้ายหน้า |
| 4 | บทความที่เกี่ยวข้อง และลิงก์ระหว่างบทความกับหน้าธุรกิจ | ผู้อ่านอ่านจบแล้วไม่มีทางไปต่อ |
| 5 | ข้อมูลโครงสร้างสำหรับ Google: ภาพ, วันที่แก้ไข, เส้นทางหน้า, คำถามพบบ่อย | เสียโอกาสแสดงผลแบบขยายในผลค้นหา |
| 6 | หน้าอังกฤษ: ชื่อหน้าต่อท้ายเป็นภาษาไทย, ภาพแนวตั้งถูกตัด | หน้าอังกฤษดูไม่เรียบร้อย |
| 7 | บันทึกการกดปุ่มทดลองใช้จากบทความ | วัดไม่ได้ว่าบทความไหนพาคนมาสมัคร |

ข้อ 3 เป็นเงื่อนไขของโครงบทความในหัวข้อ 4 ถ้ายังไม่ทำ บทความใหม่จะวางภาพได้แค่ท้ายบทความ

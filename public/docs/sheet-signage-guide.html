จอคิวจาก Google Sheet

พนักงานลงคิวและเปลี่ยนสถานะใน Google Sheet แล้วจอคิวหน้าร้านอัปเดตเองภายในประมาณ 10–20 วินาที

1. สร้าง Sheet

  1. ดาวน์โหลด template (CSV)
  2. เปิด Google Sheets → สร้างสเปรดชีตใหม่ → ไฟล์ → นำเข้า → อัปโหลดไฟล์ → "แทนที่ชีตปัจจุบัน"
  3. ไฟล์ → การตั้งค่า → ภาษา (Locale) = ประเทศไทย เพื่อให้วันที่เป็น วัน/เดือน/ปี
  4. ลบแถวตัวอย่างออก (เก็บแถวที่ 1 ที่เป็นชื่อคอลัมน์ไว้)

2. คอลัมน์

ระบบอ่านตามชื่อคอลัมน์ในแถวที่ 1 สลับลำดับ หรือเพิ่มคอลัมน์ของตัวเองได้

คอลัมน์จำเป็นบนจอ
สถานะ✅รอ · เรียก · กำลังตรวจ · เสร็จ · ยกเลิก (ว่าง = รอ)
วันที่แนะนำแสดงเฉพาะแถวของวันนี้ ถ้าไม่มีคอลัมน์นี้ = แสดงทุกแถว (เหมาะกับร้านที่ล้าง Sheet ทุกวัน)
เลขคิวอย่างน้อย 1 ใน 3ตัวเลขใหญ่บนจอ ถ้าว่างระบบใส่ 001, 002 ให้
ชื่อสัตว์อย่างน้อย 1 ใน 3ชื่อที่เรียก มีไอคอนตามชนิด
ชื่อเจ้าของอย่างน้อย 1 ใน 3ใช้เมื่อไม่มีชื่อสัตว์ ปิดบังตามการตั้งค่าจอ
ชนิด🐶 สุนัข 🐱 แมว 🐰 กระต่าย 🐦 นก 🐹 แฮมสเตอร์ อื่น ๆ 🐾
แผนก/บริการแสดงเมื่อเปิด "แสดงชื่อบริการ"
ห้องตรวจ/สัตวแพทย์แสดงเมื่อเปิด "แสดงโต๊ะ / ห้อง / ช่าง"
เวลานัดเรียงคิวตามเวลานี้
ฉุกเฉินติ๊กแล้วคิวขึ้นหน้าสุด มี 🚨
เวลาเรียกคิวที่เรียกล่าสุดขึ้นเป็นคิวหลัก (ใส่อัตโนมัติด้วยสคริปต์ข้อ 4)
เบอร์โทรไม่ถูกส่งขึ้นจอเลย

ตั้ง dropdown สถานะ: เลือกคอลัมน์ "สถานะ" → ข้อมูล → การตรวจสอบข้อมูล → เพิ่มกฎ → Dropdown: รอ เรียก กำลังตรวจ เสร็จ ยกเลิก
ช่องฉุกเฉิน: เลือกคอลัมน์ "ฉุกเฉิน" → แทรก → ช่องทำเครื่องหมาย

3. แชร์ให้ระบบ

  1. กด แชร์ มุมขวาบน → ใส่อีเมลระบบที่แสดงในหน้า จอแสดงคิว ของ portal → สิทธิ์ ผู้มีสิทธิ์อ่าน → ส่ง
  2. คัดลอกลิงก์ของ Sheet → วางในการ์ด "จอคิวจาก Google Sheet" → กด ทดสอบ → ตรวจตัวอย่าง → เปิดสวิตช์ → บันทึก

ไม่ต้องเปิด Sheet เป็น "ทุกคนที่มีลิงก์" — ข้อมูลเจ้าของสัตว์ยังเป็นส่วนตัว ระบบอ่านอย่างเดียว ไม่แก้ไข Sheet

4. (แนะนำ) ลงเวลาเรียกอัตโนมัติ

ส่วนขยาย → Apps Script → ลบโค้ดเดิม → วางโค้ดนี้ → บันทึก (ไม่ต้องกดอนุญาตอะไร) ทุกครั้งที่เปลี่ยนสถานะเป็น "เรียก" ช่องเวลาเรียกจะถูกใส่เวลาให้

function onEdit(e) {
  var range = e.range;
  if (range.getNumRows() !== 1 || range.getNumColumns() !== 1 || range.getRow() === 1) return;
  var sheet = range.getSheet();
  var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]
    .map(function (h) { return String(h).trim(); });
  var statusCol = headers.indexOf('สถานะ') + 1;
  var calledCol = headers.indexOf('เวลาเรียก') + 1;
  if (!statusCol || !calledCol || range.getColumn() !== statusCol) return;
  if (String(e.value || '').trim() === 'เรียก') {
    sheet.getRange(range.getRow(), calledCol)
      .setValue(Utilities.formatDate(new Date(), 'Asia/Bangkok', 'HH:mm'));
  }
}

ข้อควรรู้

  • จออัปเดตตามรอบรีเฟรชของจอ + ระบบอ่าน Sheet ซ้ำทุก 10 วินาที
  • ถ้า Google ล่มชั่วคราว จอแสดงข้อมูลล่าสุดที่อ่านได้ค้างไว้
  • คิวใน Sheet ไม่ส่ง LINE ให้ลูกค้า และไม่รวมในรายงานของระบบจอง
  • ถ้าการ์ดแจ้ง "แถว N อ่านไม่ครบ" ให้แก้ค่าในแถวนั้น (วันที่ / สถานะ / เวลา)
